راهنمای نصب نسخه آفلاین

۱) فایل ZIP را استخراج کن.
۲) وارد مخزن GitHub شو: sadrasabghi63-design/calisthenics-tracker3days
۳) فایل index.html قبلی را با index.html جدید جایگزین کن.
۴) دو فایل sw.js و manifest.webmanifest را هم در همان پوشه اصلی مخزن (کنار index.html) آپلود کن.
۵) در GitHub روی Commit changes بزن و حدود ۱ تا ۳ دقیقه صبر کن.
۶) یک بار سایت را با اینترنت باز کن تا فایل‌ها در حافظه مرورگر ذخیره شوند.
۷) سپس Chrome را کاملاً ببند و اینترنت را قطع کن؛ دوباره همان آدرس را باز کن.

نکته مهم:
- آفلاین شدن از اولین بازدید ممکن نیست؛ بار اول باید فایل‌ها از GitHub Pages دریافت شوند.
- اطلاعات تمرین همچنان در localStorage همان مرورگر/دستگاه ذخیره می‌شود.
- برای انتقال اطلاعات بین دستگاه‌ها از خروجی JSON و ورود JSON استفاده کن.
- اگر سایت قبلاً در مرورگر باز شده، بعد از انتشار نسخه جدید یک بار آنلاین بازش کن و صفحه را تازه‌سازی کن.
